# Trying the whac-a-mole game: a guide for labmates

*No coding, no installing, no GitHub account needed. You only need a web
browser (Chrome, Safari, Firefox, or Edge) on a computer with a keyboard.*

## The short version

1. Open the link Rehaan sent you. It opens the game full of grey with nine holes.
2. Click anywhere on the page once, so it can hear your keys.
3. Press **T** to start.
4. Play: press **1**, **2**, or **3** for the **column** a happy mole pops up in.
   Leave sad moles (or molerats) alone. When a happy mole and a sad one appear
   together, press only for the happy one.
5. At the end you'll see your results and three **Download** buttons. Click
   **Download run table (CSV)** and send that file to Rehaan.

Keys while playing: **P** pauses and resumes, **Esc** ends the run early
(press it twice if the game is in full screen). **F** before starting makes it
full screen.

## What the buttons mean

The three buttons are the three **columns**, left to right. The row a mole is
in never matters: a happy mole in the top-right hole and one in the
bottom-right hole both mean "press 3".

## Different versions

Rehaan may send you more than one link. They are the same game with different
feedback, to see which feels best:

| Version | What you'll notice |
|---|---|
| No feedback | Nothing reacts when you press. This is the design for the real study. |
| Score | A running count of happy moles you hit, top left. |
| Rings | A white ring when you hit a happy mole, a red one if you hit a sad one. |
| Sound and hammer | A good or bad sound with each press, and a little hammer that swings onto the mole. Turn your volume on. |

Please try each version you're sent and say which one kept you most focused,
and which one felt most annoying.

## If something goes wrong

- **Keys do nothing:** click on the page once, then press T again.
- **A red box says the code has not loaded:** press **Cmd+Shift+R** (Windows:
  Ctrl+Shift+R) to reload.
- **No sound in the sound version:** check your volume, and make sure you
  pressed a key or clicked in the page before the run started.
- **The game stopped or froze:** it only runs while its tab is visible. Don't
  switch tabs or windows mid-run.

## About your data

Nothing is uploaded anywhere. The game runs entirely in your browser, and the
results exist only in the file you download. These test runs are for trying
the design out, not study data.
