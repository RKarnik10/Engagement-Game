Whac-a-mole attention task

Version 0.2, built to Dr. Song's feedback of September 21, 2026: nine holes in a three-by-three grid, three buttons (one per column), a fixed one-second trial, 600 trials for a ten-minute run, happy moles to press and sad moles or molerats to skip, and no on-screen feedback of any kind.

Attention trace

Each dot is a hit. Its height is how far that reaction time strayed from the run's average, smoothed across neighbouring hits. This is a simplified version of the variance time course in Esterman et al. (2013). Above the dashed median line counts as less stable responding. Yellow ticks mark simulated scan volumes, and red marks show errors.

Run data

The run table is the one to open first: one row per mole, with its row and column, the button that should have been pressed, the button that was pressed, and the reaction time. The events table is the same run in the BIDS layout for the fMRI model. The full log keeps every event, the settings, and display-timing stats.

What is real here and what is not

The schedule, response rules, timestamps, and export format follow the project blueprint as amended on September 21, 2026. The trigger and scan volumes are simulated (further presses of T during a run are logged as real trigger pulses), the three mole drawings are not yet matched for size and brightness, and browser timing is tied to screen refresh rather than validated against scanner hardware.
