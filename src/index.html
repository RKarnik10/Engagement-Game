Attention trace

Each dot is a hit. Its height is how far that reaction time strayed from the run's average, smoothed across neighboring hits. This is a simplified version of the variance time course in Esterman et al. (2013). Above the dashed median line counts as less stable responding. Yellow ticks mark simulated scan volumes, and red marks show errors.

Run data

The events table follows the BIDS events layout (onset and duration in seconds), so it can go straight into an fMRI design matrix. The full log keeps every event, the settings, and frame-timing stats. Downloads are named by date, time, and seed.

What is real here and what is not

The schedule, response rules, timestamps, and export format follow the project blueprint. Every number in Run settings is a placeholder until Dr. Song weighs in. The trigger and scan volumes are simulated (further presses of T during a run are logged as real trigger pulses), the neutral look is not built yet, and browser timing is tied to screen refresh rather than validated against scanner hardware.
